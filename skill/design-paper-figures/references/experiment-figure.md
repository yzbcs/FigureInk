# Experiment figure

## Start from a question

Choose one:

- Where does the gain come from?
- When does the method fail?
- How does performance scale with budget, data, or model size?
- Is the benefit consistent across tasks or groups?
- What quality-efficiency trade-off changes?

## Panel map

Use one panel for the main answer and only add panels that explain mechanism, reliability, or scope. Keep method colors and labels stable across panels.

## Quantitative requirements

- exact source values and units;
- metric direction and denominator;
- uncertainty with the actual sampling unit;
- visible missing segments rather than interpolated values;
- direct labels outside bars when used;
- color-independent distinction for grayscale-critical comparisons.

Use `plot-handdrawn-paper-charts` for deterministic bars and curves.
