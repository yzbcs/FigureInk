# Introduction figure

## Purpose

Make the paper's gap and insight visible before explaining the method.

## Four-beat template

1. **Setting:** concrete user, system, data, or task context.
2. **Failure:** what prior practice gets wrong and under which condition.
3. **Insight:** the missing signal, mechanism, or decomposition.
4. **Payoff:** the changed behavior or evidence, without overstating scope.

## Useful layouts

- paired baseline/proposed outcomes;
- left-to-right cause chain;
- zoom from task context to failure mechanism;
- two-row “surface behavior / hidden cause” contrast.

## Reject when

- the figure is only a generic model pipeline;
- the failure cannot be seen;
- icons replace the scientific entities;
- the payoff implies unmeasured generality;
- the caption must introduce missing stages not shown in the figure.
