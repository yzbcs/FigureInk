# Experiment ladder

Select evidence families from the claim, not from a fixed checklist.

| Claim type | Minimum evidence | Useful extension |
|---|---|---|
| Higher effectiveness | matched main comparison | per-task or subgroup consistency |
| Better generality | multiple domains or distributions | held-out transfer |
| Mechanistic novelty | controlled ablation | substitution and interaction tests |
| More reliable | repeated trials and uncertainty | sensitivity and calibration |
| More robust | named stress condition | severity curve and failure taxonomy |
| More efficient | quality-cost frontier | scaling and hardware-normalized analysis |
| Better user outcome | defined human protocol | subgroup and disagreement analysis |

Stop adding experiments when a new table or plot does not change the claim's support, scope, or mechanism.
