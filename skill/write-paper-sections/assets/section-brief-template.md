# Section writing brief

Complete only the fields needed by the requested section. Unknown values remain typed `TBD` slots.

## Output contract

| Field | Value |
|---|---|
| Mode | `draft / revise / polish / compress / diagnose` |
| Section | `abstract / introduction / method` |
| Source format | `LaTeX / Markdown / plain text` |
| Target length | `[WORDS, SENTENCES, PARAGRAPHS, OR PAGE BUDGET]` |
| Original must be retained | `no / comments / paired before block` |
| Restructuring authorized | `yes / no / limited to [SCOPE]` |

## Immutable content

- Research question: `[QUESTION]`
- Contribution boundary: `[BOUNDARY]`
- Canonical terminology: `[TERMS]`
- Fixed citation keys: `[CITATIONS]`
- Fixed equations and labels: `[EQUATIONS_AND_LABELS]`
